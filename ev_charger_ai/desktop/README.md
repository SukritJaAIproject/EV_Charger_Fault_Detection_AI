# แผงเฝ้าระวังตู้ชาร์จ EGAT — โปรแกรมบนเดสก์ท็อป

ดับเบิลคลิกไอคอน **แผงเฝ้าระวังตู้ชาร์จ EGAT** บนเดสก์ท็อป เท่านี้จบ
โปรแกรมจะอ่านผลการวิเคราะห์รอบล่าสุด สร้างหน้าแผงควบคุม แล้วเปิดในเบราว์เซอร์
ที่ `http://127.0.0.1:8787/` โดยไม่มีหน้าต่างดำโผล่มา

ปิดโปรแกรมด้วยปุ่ม **ปิดโปรแกรม** มุมขวาบนของหน้า (ปิดแค่แท็บ โปรแกรมจะยังค้างอยู่)

## แท็บคู่มือชนิดปัญหา

แท็บที่สามอธิบายปัญหาทั้ง 7 ชนิดว่าคืออะไรและเกิดจากอะไร เปิดด้วยแถบลำดับการชาร์จ
DIN 70121 หกช่วง ตั้งแต่จับคู่สาย PLC ไปจนปิดงาน พร้อมจุดสีบอกว่าชนิดไหนเกิดได้ช่วงไหน

การ์ดของแต่ละชนิดบอกสี่เรื่อง คือ **คืออะไร / ระบบตัดสินอย่างไร / สาเหตุที่พบบ่อย /
ควรทำอะไร** บรรทัด "ระบบตัดสินอย่างไร" คัดมาจากกฎจริงใน `pipeline/ground_truth.py`
ไม่ใช่คำอธิบายลอยๆ จึงตรงกับตัวเลขที่แสดงข้างกันเสมอ พร้อมบอกด้วยว่า AI แต่ละตัว
จับชนิดนั้นได้กี่เปอร์เซ็นต์

ท้ายแท็บมีส่วน **สิ่งที่จงใจไม่นับเป็นปัญหา** เช่น การกดหยุดชาร์จเอง ฉนวนระดับ Warning
กระแสตกเพราะสองหัวแบ่งไฟกัน และเฟรม SLAC ที่ดักได้จากหัวข้างๆ ซึ่งถ้านับเป็นปัญหา
จะได้สัญญาณลวงมหาศาล

## แท็บวิเคราะห์ไฟล์ pcap

แท็บที่สองรับไฟล์ pcap จากหัวชาร์จหัวเดียว (ลากมาวางหรือกดเลือก สูงสุด 12 ไฟล์
จะเป็นไฟล์เดียวหรือทั้งวงแหวนก็ได้) แล้วบอกว่าแต่ละเซสชันพังตรงไหน

ขั้นตอนที่เกิดขึ้นเหมือนกับ pipeline ที่ใช้ทั้ง fleet ทุกประการ

1. `tshark` + ปลั๊กอิน dsV2Gshark ถอด DIN 70121 ออกจาก pcap
2. เรียงไฟล์ตามเวลา ตัดไฟล์ที่ช่วงเวลาซ้ำกับไฟล์อื่นทิ้ง (ไฟล์ `.rN` จากการโหลดซ้ำ)
3. ตัดสตรีมเป็นเซสชันการชาร์จ
4. ตัดสินว่าพังตรงไหนด้วย `pipeline/ground_truth.py` ตัวเดียวกับที่ใช้ทั้ง fleet
5. replay เฉพาะโมเดลที่เลือกไว้ แล้วบอกว่าตัวไหนจับได้ที่วินาทีที่เท่าไรของเซสชัน

**เลือกโมเดลได้ทีละตัว** มีปุ่มของทั้ง 5 ตัวพร้อมคะแนนที่ทำได้บนทั้ง fleet กดเลือกกี่ตัวก็ได้
จะไม่เลือกเลยก็ได้ ตัวเลือกจำไว้ในเบราว์เซอร์ และผลลัพธ์จะแสดงทุกตัวที่รัน ตัวที่ไม่เตือน
ก็ขึ้นว่า "ไม่เตือน" ไม่ใช่หายไปเฉยๆ

โปรแกรม import เฉพาะโมเดลที่เลือก ดังนั้น

* **Multi-Agent ตัวเดียว** ใช้กฎล้วน ไม่ต้องมี torch และไม่ต้องมีไฟล์โมเดลที่เทรนไว้
  ไฟล์ 54 KB ใช้เวลาไม่ถึง 1 วินาที
* **ครบทั้ง 5 ตัว** ไฟล์เดียวกันใช้เวลาราว 12 วินาที
* ถ้าโมเดลไหนขาดไฟล์ที่เทรนไว้หรือ import ไม่ได้ จะข้ามเฉพาะตัวนั้นและบอกเหตุผล
  ไม่ล้มทั้งงาน

ผลลัพธ์บอกจำนวนเซสชัน จำนวนที่มีปัญหา และรายเซสชันบอกชนิดปัญหา ข้อความจริงจาก
โปรโตคอล และเวลาที่เกิดนับจากต้นเซสชัน

**ใช้เวลาประมาณ 20 วินาทีต่อไฟล์ 4-5 MB** เพราะปลั๊กอิน V2G ถอดช้า งานรันแยก process
ถ้าพังก็ไม่ลากเซิร์ฟเวอร์ล้ม ไฟล์ที่อัปโหลดถูกลบทิ้งทันทีที่วิเคราะห์เสร็จ

แท็บนี้ทำงานได้เฉพาะตอนเปิดผ่านโปรแกรมบนเดสก์ท็อป หน้าที่เผยแพร่บนเว็บทำไม่ได้
เพราะต้องใช้ tshark กับโมเดลบนเครื่อง และจะขึ้นข้อความอธิบายแทน

การวิเคราะห์รันด้วย Python ของ conda env `ev_ai` (ต้องมี torch กับ xgboost)
ส่วนตัวโปรแกรมยังใช้ Python ระบบที่มีแค่ไลบรารีมาตรฐาน ถ้าย้ายเครื่องแล้ว path
ไม่ตรง กำหนดตัวแปร `EV_AI_PYTHON` ให้ชี้ไปที่ python ที่มีโมเดลได้

## โดนัทภาพรวมทั้ง fleet

แผงแรกในแถวกราฟแบ่งสัดส่วนภาพรวม สลับดูได้สามแบบ

* **ความเร่งด่วน** — ต้องส่งช่าง / เฝ้าระวัง / ปกติ จาก 212 สถานี
  (ติดธงเมื่ออัตราเสีย 15% ขึ้นไป หรือหัวจ่ายสองข้างต่างกันเกิน 8 จุด
  สีแดงคือ 20% ขึ้นไป หรือต่างกันเกิน 15 จุด)
* **ชนิดปัญหา** — แต่ละเคสคิดเป็นกี่ % ของปัญหาทั้งหมด 5,075 ครั้ง
  ชนิดที่ต่ำกว่า 2% รวมเป็น "อื่นๆ" เพื่อไม่ให้วงแตกเป็นเสี้ยวเล็กจนอ่านไม่ออก
  (เอาเมาส์ชี้จะบอกว่ามีอะไรอยู่ข้างใน และชนิดนั้นเป็นปัญหาเด่นที่กี่สถานี)
* **สถานะงานซ่อม** — ขยับตามที่ทีมกดเปลี่ยนสถานะจริง ใช้ดูความคืบหน้าได้

คลิกส่วนไหนก็ได้ (หรือคลิกที่บรรทัดในคำอธิบาย) เพื่อกรองรายการสถานีให้เหลือเฉพาะกลุ่มนั้น
โหมดชนิดปัญหาจะกรองเป็น "สถานีที่ชนิดนั้นเป็นปัญหาเด่น" ตรงกับคอลัมน์ปัญหาเด่นในตาราง
แล้วกด **ล้างตัวกรอง** มุมขวาบนของแผงเพื่อกลับมาดูทั้งหมด

## ธีมและคีย์ลัด

หน้าเป็น **ธีมมืด** เป็นค่าเริ่มต้น กดปุ่ม ☀ / ☾ มุมขวาบนสลับเป็นธีมสว่างได้
ธีมที่เลือกจำไว้ในเบราว์เซอร์เหมือนภาษา

| คีย์ | ทำอะไร |
|---|---|
| ↑ ↓ | เลื่อนสถานีขึ้นลงในรายการ (แผงขวาเปลี่ยนตาม) |
| Home / End | ไปสถานีแรกหรือสุดท้ายของรายการที่กรองอยู่ |
| Enter / Space | เลือกแถวที่โฟกัสอยู่ |

ลิงก์บนแถบที่อยู่จะเปลี่ยนตามสถานีที่เลือก เช่น `...#s=063_Kanchanapisek2`
ก๊อปส่งให้เพื่อนได้เลย เปิดแล้วเด้งไปสถานีนั้นทันที

## สองภาษา — Bilingual

ปุ่ม **ไทย / EN** มุมขวาบนสลับภาษาได้ทั้งหน้า ทั้งหัวข้อ ตาราง คำอธิบายกราฟ
ข้อความแนะนำ และ tooltip ภาษาที่เลือกจำไว้ในเบราว์เซอร์ เปิดใหม่ครั้งหน้าได้ภาษาเดิม
(ชื่อสถานีเป็นข้อมูลดิบ จึงแสดงตามที่บันทึกมาเสมอ)

*The **ไทย / EN** switch at the top right changes every label, caption, hint and
tooltip on the page. The choice is remembered in the browser. Station names are
raw data and always show as recorded.*

## ต้องมีอะไรบ้าง

* Python 3 บนเครื่อง (ใช้เฉพาะไลบรารีมาตรฐาน ไม่ต้อง `pip install` อะไรเลย)
* โฟลเดอร์ผลการวิเคราะห์ที่รันเสร็จแล้ว — หาให้อัตโนมัติตามลำดับ
  `%EV_AI_DATA%` → `E:\ev_charger_ai_data_v3` → `E:\ev_charger_ai_data`
* ไม่ต้องต่อเน็ต (ต่อเน็ตแล้วฟอนต์จะสวยขึ้นเท่านั้น)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | ตัวโปรแกรม: สร้างข้อมูล เปิดเว็บเซิร์ฟเวอร์ที่ localhost เก็บสถานะงานซ่อม |
| `build_data.py` | ย่อผลรอบล่าสุดทั้งรอบให้เหลือ `build\fleet.json` |
| `dashboard.tmpl.html` | หน้าแผงควบคุม (ไฟล์เดียวใช้ได้ทั้งบนเครื่องและบนเว็บ) |
| `Start Dashboard.bat` | เปิดแบบเห็นหน้าต่างข้อความ ใช้ตอนหาสาเหตุเวลามีปัญหา |
| `make_icon.py` | สร้าง `icon.ico` ใหม่ (ต้องมี Pillow) |
| `state\triage.json` | สถานะงานซ่อมรายสถานี — ไฟล์นี้คือของมีค่า ควร backup |
| `state\app.log` | log ของโปรแกรม |
| `build\` | ไฟล์ที่สร้างอัตโนมัติ ลบได้ตลอด เดี๋ยวสร้างใหม่ |

## ตัวเลือกตอนรัน

```
python app.py                 เปิดตามปกติ
python app.py --rebuild       บังคับอ่านข้อมูลใหม่ก่อนเปิด
python app.py --port 9000     เปลี่ยนพอร์ต
python app.py --no-browser    รันเฉยๆ ไม่เปิดเบราว์เซอร์
```

ปกติโปรแกรมจะอ่านข้อมูลใหม่เองเมื่อ `sessions\index.json` ของรอบนั้นใหม่กว่า
`build\fleet.json` หรือกดปุ่ม **รีเฟรชข้อมูล** บนหน้าแผงก็ได้

เปิดซ้ำได้ไม่ต้องกลัว ถ้าโปรแกรมรันอยู่แล้วมันจะเปิดแค่แท็บใหม่ ไม่เปิดซ้อน

## สถานะงานซ่อมเก็บที่ไหน

หน้าเดียวกันนี้ทำงานได้ 3 แบบ และเลือกเองตอนเปิด

1. **เปิดจากโปรแกรมนี้** → เก็บที่ `state\triage.json` ข้างๆ โปรแกรม
2. **เปิดจากลิงก์ที่เผยแพร่บน claude.ai** → เก็บบนคลาวด์ ทุกคนที่เปิดลิงก์เห็นตรงกัน
3. **ดับเบิลคลิกไฟล์ html ตรงๆ** → ดูได้อย่างเดียว บันทึกไม่ได้

## ถ้ามีปัญหา

* ขึ้นว่า *ไม่พบผลการวิเคราะห์* — ไดรฟ์ E: ยังไม่ได้ต่อ หรือกำหนด `EV_AI_DATA`
  ให้ชี้ไปโฟลเดอร์ผลที่ต้องการ แล้วเปิดใหม่
* เปิดแล้วไม่ขึ้นอะไร — รัน `Start Dashboard.bat` จะเห็นข้อความบอกสาเหตุ
  หรือดูท้ายไฟล์ `state\app.log`
* พอร์ต 8787 ถูกใช้อยู่ — โปรแกรมจะไล่หาพอร์ตว่างถัดไปให้เอง
